# Changelog — v0.1.0 (planned)

> Pre-release notes. Updated as the implementation progresses.

## Headline

The first public release. Adds **tab groups**, **right-click menu**, **smart paste**, and a polished first-run experience on top of wezterm.

## What's in

- Workspace + crates wired.
- First-run setup, no config needed.
- Right-click context menu on tab bar and on pane.
- `Split right` (vertical) and `split down` (horizontal).
- Connect to: `cmd.exe`, `powershell.exe`, `pwsh.exe`, `wsl.exe`, Git Bash, Nushell.
- Tabs: open, close, rename, reorder, focus next/prev.
- Tab groups: create, name, activate by hotkey, persist, restore.
- Group picker (`Ctrl+Shift+G P`).
- Save / restore groups to a JSON file.
- Clipboard: copy, copy as HTML, paste, paste as quote, paste as base64.
- Bracketed paste on by default.
- Smart paste detection.
- Bundled font presets.
- Reload config without restart.
- CI: Windows + Linux + macOS builds pass.
- `cargo deny check licenses` clean.
- THIRD-PARTY-NOTICES.md generated.

## What's out

- Broadcast input — v0.2.0.
- VS Code theme import — v0.3.0.
- Status bar — v0.4.0.
- SSH, profiles, SFTP — v0.5+.

## Migration notes

This is the first release. There is no migration from a previous version.
