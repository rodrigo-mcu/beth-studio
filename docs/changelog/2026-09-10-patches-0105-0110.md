# 2026-09-10 — Patches 0105–0110 (para teste)

Notas do que mudou desde o commit `ea0528c` (rebrand / 0066–0104).
Instalador de teste: `dist/BethTerm-Setup.exe` (rebuild local; não vai no git).

## Como testar

1. Feche todo BethTerm (e uma cópia antiga do WezTerminator, se ainda estiver aberta — mesma window class).
2. Rode `dist\BethTerm-Setup.exe` do workspace.
3. Abra pelo atalho do Desktop / Menu Iniciar (não pelos `run-bethterm-*.cmd`; esses ainda usam `--always-new-process` de propósito).

## 0105–0107 — Fechar vai para o ícone do relógio

- O X da janela (e Alt+F4) **esconde** a janela. Os PTYs continuam.
- Ícone perto do relógio: clique restaura; clique direito empilha as janelas escondidas.
- **Sair** no menu do ícone é o que realmente encerra.
- 0107: se o ícone não for criado, o hide é desfeito (não some a janela sem ícone).

## 0108–0109 — Atalho reusa o processo; sem janela branca extra

- Segundo clique no atalho **não** abre outro processo GPU. Foca o GUI que já está rodando (e restaura o que estava no tray).
- A janela branca enorme de probe WGL deixa de aparecer: agora é 1×1, hidden, e é destruída depois do probe.

Os launchers de desenvolvimento (`run-bethterm-release.cmd` / `run-bethterm-debug.cmd`) continuam com `--always-new-process`.

## 0110 — Tema default em todos os terminais

No Settings (clique direito → **Configure this terminal…**):

| Botão | Efeito |
| --- | --- |
| **Apply** | Só neste terminal |
| **Usar em todos** | Pinta todos os panes abertos e grava o padrão |

- Badge **default** no card escolhido.
- Arquivo: `%APPDATA%\bethterm\default-theme.json`.
- Aba/janela nova sem tema próprio nasce com esse padrão.
- Split continua herdando o terminal de origem (0054).
