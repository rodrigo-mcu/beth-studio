# 2026-09-23 — Patches 0149–0156 (para teste)

A interface foi trocada. Os shells continuam no `bethterm-host.exe`.
O ícone perto do relógio é o menu destas funções.

## 0149 — Reabrir a interface não derruba as janelas

Restaurar a posição salva chamava o Windows enquanto a janela ainda
estava emprestada. A interface nova morria e o host ficava sem janelas.
Agora a posição é aplicada com o empréstimo solto.

## 0150 — Esconder tudo

No menu do ícone, **Esconder tudo** manda todas as janelas visíveis
para a bandeja, do mesmo jeito que o X de cada uma. Os terminais
seguem. Cada uma volta pela lista do ícone.

## 0151 — Cor do ícone na barra de tarefas

Clique direito na janela → **Cor do ícone**. Padrão, Azul, Verde,
Laranja, Vermelho, Roxo, Amarelo, Ciano, Rosa. A cor fica no botão
daquela janela e no Alt+Tab, e é gravada com o nome em
`%APPDATA%\bethterm\host-windows.json`.

## 0152 e 0153 — Agente esperando

O mesmo aviso da bolinha na aba (sino, OSC 9, OSC 777, OSC 99, ou uma
variável `*_status=waiting`) também marca:

- um ponto vermelho no ícone da janela na barra de tarefas
- o mesmo ponto no ícone da bandeja, com a dica "agente esperando"
- um `●` na frente do nome daquela janela no menu do ícone

Vale para Claude, Codex, OpenCode, Cursor, Grok e qualquer CLI que
mande um desses avisos. O OSC 99 é lido pelo host: o executável novo
está em `bethterm-host.exe.new` e só entra na próxima subida do host.

## 0154 — Menu que sumia

Se um menu ficava preso, o Windows respondia 1446 e todo clique
seguinte não abria nada. Agora esse menu preso é cancelado e o menu
pedido abre.

## 0155 — GPU ou CPU

Menu do ícone → **Desenho**.

- **GPU (placa de vídeo)** é o padrão.
- **CPU** desenha com o Mesa ao lado do programa, sem usar a placa.

Trocar reinicia só a interface. Os shells continuam. A escolha fica em
`%APPDATA%\bethterm\render-mode`.

## 0156 — Abrir pelo menu vem maximizado

Clicar uma janela na lista do ícone, ou **Abrir todas**, abre essa
janela maximizada.

## O que não muda

`bethterm-host.exe` que já está rodando não é reiniciado por estas
trocas. **Reiniciar interface (terminais continuam)** e a troca
GPU/CPU fecham só as janelas.
