A mouse-first terminal for Windows

Terminals that outlive the interface.

Beth Studio separates your terminals from the interface. A persistent host owns your shells, AI agents and WSL sessions. If the interface freezes, or you restart it, everything keeps running.

Download for Windows View on GitHub

Open source. Windows 10 or 11. Linux and macOS: planned, no date.

The problem

In ordinary terminals, the terminal and the graphical interface live in the same process. When the interface freezes or slows down, your terminals die with it and you lose whatever was running. The trouble is almost always the interface, not the console.

How it works

  1. The host owns the terminals. bethstudio-host.exe (derived from WezTerm) holds every shell, agent and WSL session.
  2. The interface is just a layer. Studio (Go + React in WebView2) connects to the host and displays the terminals. Closing, freezing or restarting the interface does not touch them.
  3. Update without losing anything. Under Settings > About > Reload interface the new interface comes in and the host keeps running.
  4. If the host itself goes down, Studio starts another one and recreates the terminals in the same tabs and folders. What was running inside them is not recovered, only the shell, folder, title and position.

Features

A terminal and the tools around it, in one program.

  • Update without killing terminals

    Reload the interface without restarting Studio and without touching the host. Terminals and agents stay alive.

  • Built-in task manager

    CPU, memory, GPU and disk for the computer, plus what each terminal consumes. It helps you tell whether the weight is in the interface or in the programs you run.

  • Paste an image or file into the terminal

    Copy a screenshot or a file in Explorer and paste: Studio saves a file and pastes its path so the agent can open it. In WSL, C:\… becomes /mnt/c/….

  • Mouse first

    New tab, split, theme, font and detach to a window: everything is done by clicking, with no config file and no shortcuts to memorize.

  • Tabs, splits and search

    Tabs, draggable splits, search, and sidebar views by organization, type or folder.

  • All terminals

    A grid with one card per terminal, showing a text preview of its screen, so you can find the one you want at a glance.

  • Detached terminal

    Move a terminal to its own window, even on another monitor, and drag it back to the tabs. It keeps running the whole time.

  • Agent waiting

    An amber dot tells you when an AI agent stopped and is waiting for you, on the tab, in the sidebar and in the tray. Notification and sound are optional.

  • Voice dictation

    Speak, review the text and send it to the terminal, with optional correction by an AI model.

    uses the AI provider you configure

  • Database client

    Built-in client for PostgreSQL, MySQL/MariaDB, SQL Server and SQLite: object tree, SQL with autocomplete and saved queries.

  • SSH, serial and SFTP

    Saved SSH hosts and serial ports, and an SFTP window with local and remote panes.

  • Editor and notes

    Open and edit text and Markdown, with a formatted preview, and keep notes that save themselves.

  • Browser and phone

    Use the full Studio in another computer's browser, or a dedicated phone page to talk to your agents. Off by default.

    needs a server of your own

  • Self-recovery

    If the host goes down, Studio starts it again and recreates the terminals in the same tabs and folders.

  • WSL with smart startup

    A WSL terminal waits for the distro to respond and the folder to appear before opening, instead of closing right away or landing in the wrong folder.

  • Themes and fonts

    Gogh and VS Code style themes, font choice, and theme and font per terminal.

Built for heavy use

The author uses Beth Studio every day with about 35 terminals open at the same time.

That means WSL2 and PowerShell sessions, several AI agents and long builds. In the author's experience, typing stays smooth in that setup, and the built-in monitor showed that the bottleneck was not WSL2.

This is real use of the project, not a performance test: there are no published measurements and no comparison with other products.

Download and install

From the repository's Releases page. Requires Windows 10 or 11.

BethStudio-Setup.exe

Single-file installer. Recommended.

BethStudio-<version>-windows-x64.zip

Portable version: unzip it and open bethstudio-web.exe.

Open the Releases page

  1. Download BethStudio-Setup.exe and check the file against SHA256SUMS.txt.
  2. Run it, pick a folder and click Install (the button label in the installer is in Portuguese).
  3. Open Studio from the shortcut or from the installer's open button.

The install is portable: no Windows registry entries and no hidden folders. Updating while the host is running does not take down your terminals.

Linux and macOS: planned

Today Beth Studio runs on Windows only. There are plans to port it to Linux and macOS, but with no date and no commitment to deliver.
